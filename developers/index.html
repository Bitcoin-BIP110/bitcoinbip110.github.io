Consensus boundary

Height 961,640 changes proof of work and header format

PropertyBefore 961,640From 961,640
Proof of workSHA-256dBLAKE2b
Header size80 bytes164 bytes
Header generationLegacyVersion 2

Applications that delegate validation to Bitcoin Knots can consume normalized RPC output. Independent raw-header validators must implement the reference version-2 BLAKE2b rules.

Signing and replay

SIGHASH_UNIFIED

SIGHASH_UNIFIED is opt-in per signature, uses hash-type bit 0x20, and requires the value and scriptPubKey of every spent output. Ordinary signatures can remain replayable when the same pre-fork inputs are valid on both histories.

Engineering tests

Regtest activation controls

-testactivationheight=blake2b@<height>
-rdtsexpiry=<unix_time>
-blake2b_headline=<headline>

These reference-node arguments allow controlled transition testing without depending on mainnet timing.
